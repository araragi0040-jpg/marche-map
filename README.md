# めぐるマルシェマップ v5

スマホ公開画面とPC専用の簡易CAD編集画面を分離したデモ版です。

## 公開

`index.html` をそのまま GitHub / Vercel に配置できます。

## 公開画面

通常URLではスマホ向け公開画面のみ表示します。

- 運営からのお知らせ
- 会場マップ
- 出店者一覧
- 店舗詳細

## PC編集画面

URL末尾に `?manage=1` を付けると、右上に運営認証ボタンが表示されます。

例：

```text
https://example.vercel.app/?manage=1
```

デモ用パスコード：

```text
marche2026
```

認証記録は取得しません。セッション中だけ編集画面を開けます。

## 編集機能

- 会場の横幅・縦幅をm単位で指定
- 長方形・角丸長方形・L字型を選択
- 0.5m / 1m / 2mグリッド
- 飲食・物販・体験・円形ブースをパレットから追加
- 入口・受付・ステージ・休憩・設備をパレットから追加
- 各オブジェクトの形状、サイズ、座標、店舗情報を編集
- 誤操作防止のため、選択後に「配置移動ON」にしてからドラッグ
- JSON入出力
- ブラウザ内保存

## 共有編集について

このデモの「保存」は端末ごとのブラウザ内保存です。複数メンバーの編集結果を共通反映するには、次段階で以下のどちらかを接続します。

1. Googleスプレッドシート + GAS
2. Supabaseなどの共有データベース

ニュースサイトの管理者権限と連動する場合は、デモ用パスコード部分を既存認証に置き換えます。
